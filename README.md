# Module 01 – Cybersecurity & Networking Foundations

**Duration:** Day 1–Day 5  
**Level:** Beginner  
**Project type:** Cybersecurity learning notes and safe practical lab documentation

This repository is organized around the objectives shown in the Module 01 task brief.

## Learning objectives

1. Learn cybersecurity fundamentals: CIA Triad, threats and attack surfaces; and networking basics: IP, MAC, ports and protocols.
2. Understand OSI and TCP/IP models, HTTP/HTTPS, DNS, DHCP, authentication and authorization.
3. Set up a safe security lab, inspect network information and identify ports/services in a controlled environment.
4. Document the setup and findings in a Cybersecurity Fundamentals Report and Practical Lab Record.

## How to complete the practical work

1. Read the learning notes.
2. Use your own Windows computer or an authorized lab machine.
3. Follow the commands in `Practical-Lab/Practical-Lab-Record.md`.
4. Record your actual outputs in the observation tables. Do not copy example values or publish private IP/MAC details unnecessarily.
5. Add screenshots with private information blurred or cropped.
6. Complete the report with your own findings and limitations.
7. Review the LinkedIn draft and publish it only after completing the activities.

## Safety and scope

- Only inspect devices and networks you own or have explicit permission to assess.
- The exercises are limited to local configuration, DNS lookup, basic connectivity checks and viewing local listening connections.
- Do not scan public IP ranges, attempt unauthorized access, capture other people's traffic, or test services without permission.
- Do not commit passwords, tokens, public IP addresses, full MAC addresses, Wi-Fi credentials or unredacted screenshots to GitHub.
